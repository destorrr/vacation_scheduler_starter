# Vacation Scheduler — стартовый каркас

Стек: Python 3.12, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL 16, Jinja2, Bootstrap, openpyxl.

## Включено
- 12 таблиц предметной области;
- отдельный учёт сотрудников в каждой организации;
- несколько периодов отпуска на один план, календарная продолжительность включительно;
- неизменяемые оригиналы Excel-шаблонов с версиями;
- авторизация Argon2, роли `central_hr` и `responsible`, CSRF-защита;
- серверная проверка доступа к организациям;
- интерфейс центрального HR для создания ответственных, назначения организаций, блокировки учётных записей и сброса пароля;
- аудит создания и изменения учётных записей;
- Docker Compose и начальная миграция Alembic.

## Первый запуск
1. Скопируйте `.env.example` в `.env`.
2. Установите уникальные `SECRET_KEY` (не менее 32 случайных символов) и `POSTGRES_PASSWORD`.
3. Проверьте, что `DATABASE_URL` содержит те же имя БД, пользователя и пароль, что и параметры PostgreSQL.
4. При работе за HTTPS reverse proxy установите `SESSION_HTTPS_ONLY=true`.
5. Выполните `docker compose up -d --build`.
6. Примените схему: `docker compose exec app alembic upgrade head`.
7. Создайте первого администратора: `docker compose exec app python -m app.cli create-admin`.
8. Откройте приложение на порту 8000 и войдите созданным пользователем.

## Управление доступом
- Центральный HR видит все активные организации и управляет учётными записями ответственных на странице «Пользователи».
- Ответственный видит только назначенные ему организации.
- Пользователь может быть назначен сразу на несколько организаций.
- Для каждого ответственного требуется минимум одна активная организация.
- Центральный HR может деактивировать учётную запись или установить новый пароль.
- Изменения учётных записей и назначений фиксируются в `audit_log`.

## Миграции
Миграция `0001_initial_schema` создаёт исходную схему из SQLAlchemy metadata как bootstrap для чистой БД. Это одноразовая начальная миграция. После её применения все последующие изменения структуры нужно оформлять обычными явными Alembic-миграциями, не переписывая уже применённые ревизии.

## Ограничения текущего этапа
Создание организаций доступно центральному HR. Импорт Excel, сопоставление сотрудников и заполнение копии Т-7 будут реализованы на следующих этапах. Перед публикацией в интернете необходимы HTTPS, reverse proxy и корректные секреты окружения.
